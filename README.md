# TileLayout

Помогает выбрать раскладку плитки на полу: откуда начинать, где окажутся подрезки
и как это будет выглядеть от порога.

Считает не количество материала, а **дизайнерское решение**. Даёт несколько именованных
вариантов раскладки, оценивает каждый объективными метриками в миллиметрах и объясняет
выбор словами, которые можно передать плиточнику.

## Что умеет

- **Вид от входа.** План разворачивается так, как помещение видно с порога, и симметрия
  считается относительно оси дверного проёма, а не оси комнаты. Когда дверь смещена от
  центра стены — это разные раскладки.
- **Видимость подрезок.** Мебель прячет подрезки под собой, и для подвесной мебели это
  считается геометрически: под тумбой с кромкой на 250 мм пол просматривается примерно
  на 220 мм, а дальняя полоса скрыта корпусом.
- **Дверной проём.** Плитка продолжается в проём и режется одним сквозным куском —
  отдельная вставка по линии стены выглядит как ошибка.
- **Отраслевые правила.** Перевязка в половину запрещена для плитки от 900 мм: на длинной
  стороне возникает перепад плоскости. Подрезки тоньше 50 мм отсеиваются — такие крошатся
  при резке.
- **Наряд для укладчика.** Раскладка переводится в две разметочные линии от стен и список
  размеров кусков.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # юнит-тесты движка
npm run build    # статическая сборка в out/
```

## Как устроено

Геометрический движок — [`src/engine`](src/engine), чистый TypeScript без зависимостей
от React, покрыт юнит-тестами. Интерфейс его только отображает.

| Модуль | Отвечает за |
|---|---|
| [`grid.ts`](src/engine/grid.ts) | построение сетки плиток в заданных границах |
| [`strategies.ts`](src/engine/strategies.ts) | кандидаты смещения сетки по каждой оси |
| [`metrics.ts`](src/engine/metrics.ts) | подрезки, симметрия, отход |
| [`entry.ts`](src/engine/entry.ts) | оценка и разворот плана от входа |
| [`objects.ts`](src/engine/objects.ts) | мебель и геометрия видимости пола под ней |
| [`threshold.ts`](src/engine/threshold.ts) | пол в дверном проёме |
| [`instructions.ts`](src/engine/instructions.ts) | наряд для укладчика |

Бэкенда и базы нет: расчёт — чистая функция от нескольких десятков чисел, выполняется
в браузере за миллисекунды.

Принятые решения и их обоснования — в [SPEC.md](SPEC.md). Долгосрочное видение
продукта — в [tech_spec.md](tech_spec.md).

## Ограничения

Помещение считается идеальным прямоугольником. В реальности стены расходятся на 10–30 мм
на три метра, и опытный плиточник компенсирует именно это выбором старта — перед укладкой
промерьте обе стены каждой пары.

Вне текущей версии: стены и потолок, помещения сложной формы, диагональ и ёлочка, 3D,
распознавание планов БТИ.
